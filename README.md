# ceniflix

CineFlix is a Flutter-based mobile application that allows users to browse movies, select seats, and book tickets easily from their smartphones.

How to Use the App

Register and Login
Create a new account using your email and password, or log in with your existing credentials. You can also enable fingerprint login for faster access.

Browse Movies
Explore movies under “Now Showing” and “Coming Soon.” Tap on any movie to view details such as genre, duration, rating, and description.

Select Showtime & Seats
Choose your preferred showtime and select available seats using the interactive seat layout.

Make Payment
Proceed to payment using the Khalti payment gateway. Complete the transaction to confirm your booking.

View Booking History
Access your booking history to see past and current reservations. You can also cancel bookings if needed.

Manage Profile
Update your personal information and upload a profile picture from your camera or gallery.

Key Features

Secure email/password authentication

Biometric (fingerprint) login

Interactive seat selection

Khalti payment integration

Booking history tracking

Profile management

Sensor-based interaction (shake detection)
